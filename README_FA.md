# WICK HUNTER — ربات آزمایشی غربالگری فیوچرز KCEX

**نسخه پیش‌نمایش پژوهشی؛ سفارش خرید/فروش ارسال نمی‌کند.**

این پروژه اسکن خودکار را از اندیکاتور TradingView جدا می‌کند. اسکریپت روی سرویس اجرای خودکار GitHub Actions (یا رایانه شخصی) اجرا می‌شود؛ برای هر اجرا نیازی به روشن بودن گوشی نیست. ابتدا فهرست فیوچرز USDT و تغییرات ۲۴ ساعته KCEX را می‌خواند؛ تا سقف ۵۰ کاندیدای پرتوجه را بر اساس رشد انتخاب می‌کند؛ کندل‌های ۱۵ دقیقه‌ای بسته‌شده را برای حجم نسبی، رشد ۱ساعته و مناطق مقاومت گذشته/تخمین ATR بررسی می‌کند؛ در صورت نزدیک‌شدن به منطقه، کندل‌های ۱ دقیقه‌ای را برای شکست دو کف صعودی تأییدشده بررسی می‌کند. اگر Telegram BOT TOKEN و CHAT ID تنظیم شده باشند، هشدار پژوهشی می‌فرستد.

## ⚠️ محدودیت تعیین‌کننده داده‌های KCEX

تعداد زیادی از منابع عمومی **مستندات رسمی کامل و تأییدشده کندل‌های KCEX** را ارائه نمی‌دهند. این نسخه از یک مسیر تیکر مشاهده‌شده در کد یک کلاینت مستقل و **مسیر کندل حدسی مشابه API فیوچرز MEXC** استفاده می‌کند:

- تیکر: `https://www.kcex.com/fapi/v1/contract/ticker`
- کندل احتمالی، **تأییدنشده**: `https://www.kcex.com/fapi/v1/contract/kline/ARIA_USDT?interval=Min15`

**این بخش از محیط فعلی به‌صورت زنده آزمایش نشده است.** اگر KCEX مسیر یا قالب متفاوتی داشته باشد، برنامه خطای واضح می‌دهد و **هشدار ساختگی نمی‌فرستد**. حتی اگر موفق شد، به معنی صحت/سودآوری استراتژی نیست. هیچ‌وقت داده‌های MEXC یا Binance را بی‌اطلاع جای KCEX نشان نمی‌دهد.

## قدم اول: اجرای تست آفلاین (قبل از تلگرام)

برای اطمینان از نصب کد:

```bash
python scanner.py --demo
python -m unittest discover -s tests -v
```

`--demo` **فقط داده ساختگی** تولید می‌کند و هیچ قیمت زنده‌ای را بازتاب نمی‌دهد. بعد از تست، اولین آزمایش زنده را با `python scanner.py` اجرا کنید؛ بدون توکن تلگرام فقط نتیجه را در لاگ و `report.json` نمایش می‌دهد. اگر خطای KCEX رخ داد، متن خطا را ثبت کنید. **نباید تصور کرد اسکنر فعال است.**

## قدم دوم: راه‌اندازی از طریق گوشی / GitHub

۱. در `github.com` حساب رایگان بساز و یک مخزن جدید (ترجیحاً `Public`) به نام `wick-hunter-kcex` بساز. برای فعال کردن گزینه‌های دسکتاپ در مرورگر گوشی از Chrome → `Desktop site` استفاده کن.

۲. محتویات فایل ZIP را باز کن و این فایل‌ها را در همان مسیرها به مخزن منتقل کن: `scanner.py`، `state.json`، `report.json`، `README_FA.md`، `tests/test_scanner.py` و `.github/workflows/scan.yml`.

۳. از بخش **Actions → Wick Hunter KCEX → Run workflow** اجرای دستی را بزن. بخش Logs را باز کن و تأیید کن که پیام `Scan:` دیده می‌شود. در اجرای دستی، فایل `wick-hunter-report` نیز در صفحه همان اجرا قرار می‌گیرد. **اول باید این تست زنده موفق شود.** اگر خطای `DATA ERROR` یا `All KCEX OHLC requests failed` دیدی، ربات هنوز کار نمی‌کند؛ پیام کامل خطا برای رفع اتصال داده لازم است.

۴. فقط بعد از موفق شدن اتصال داده‌ها، در تلگرام به `@BotFather` پیام `/newbot` بده و توکن یک ربات جدید بساز. ربات خودت را Start کن. برای گرفتن شناسه چت می‌توان از `getUpdates` رسمی Telegram Bot API بعد از فرستادن پیام به ربات استفاده کرد. اگر شناسه را نمی‌شناسی، کمک بگیر و **توکن را در چت، فایل عمومی یا تصویر منتشر نکن**.

۵. در GitHub → **Settings → Secrets and variables → Actions → New repository secret** دو مقدار را ثبت کن:

- `TELEGRAM_BOT_TOKEN` — توکن خصوصی ربات
- `TELEGRAM_CHAT_ID` — شناسه عددی چت گیرنده

۶. دوباره **Actions → Run workflow** اجرا کن. پیام‌های `PRE/ WATCH` اطلاع‌رسانی هستند، نه دستور شورت.

### زمان‌بندی و هزینه

فایل `.github/workflows/scan.yml` اجرای زمان‌بندی‌شده را تقریباً هر ۵ دقیقه درخواست می‌کند. **GitHub اجرای دقیق هر ۵ دقیقه را تضمین نمی‌کند و ممکن است دیر برسد یا رد شود**؛ بنابراین این راهکار برای ورودهایی که در ۱ تا ۳ دقیقه تمام می‌شوند مناسب نیست. زمان‌بندی روی شاخه پیش‌فرض فعال می‌شود. برای مخزن عمومی اجرای استاندارد Actions طبق مستندات GitHub رایگان است؛ در مخزن خصوصی سهمیه ماهانه محدودیت دارد. مخزن عمومی غیرفعال نیز ممکن است پس از ۶۰ روز غیرفعال شود.

### هشدارهای ارسال‌شده

- `WATCH`: رشد یک ساعت و حجم نسبی از حد آزمایشی گذشته و قیمت به ناحیه احتمالی نزدیک شده؛ **فقط بررسی دستی**.
- `MINI BREAK`: بعد از شناسایی منطقه در یک اجرای قبلی، شکست دو پیوت کف صعودی تأییدشده مشاهده شده؛ هنوز ممکن است شکست فیک باشد.

اگر داده کافی یا قیمت تازه در دسترس نبود، اسکنر از اعلام نتیجه خودداری می‌کند.

### تنظیمات اختیاری (GitHub Actions env یا اجرای شخصی)

- `MAX_SYMBOLS=50` : تعداد ارزهای منتخب برای واکاوی؛ به‌صورت پیش‌فرض همه ارزها اسکن نمی‌شوند و ابتدا ۵۰ نماد پررشد انتخاب می‌شود.
- `MIN_24H_USDT=150000` : حداقل گردش ۲۴ساعته؛ از داده‌های خود صرافی.
- `MIN_1H_PCT=5` و `MIN_RVOL=1.5` : رشد یک ساعت و حجم نسبی.
- `NEAR_PCT=7` : حداکثر فاصله نزدیکی به منطقه (درصد).
- `KCEX_BASE_URL`, `KCEX_TICKER_PATH`, `KCEX_KLINE_PATH` : فقط اگر مسیر صحیح را از منبع قابل‌اعتماد تأیید کردی تغییر بده.
